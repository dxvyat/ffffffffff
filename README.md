# DXV PRIVATE TWEEK

WinForms-инструмент для Windows 10/11 x64, который применяет только явно выбранные настройки и сохраняет резервные копии для отката. Универсального твика, гарантирующего одинаковый прирост FPS на каждом ПК, не существует, поэтому изменения здесь опциональны и обратимы.

## Что входит

- мастер запуска с выбором точки восстановления Windows;
- игровой режим Windows и отключение фоновой записи Game Bar;
- отключение ускорения мыши и настройка задержки клавиатуры;
- переключение на встроенный план высокой производительности с сохранением исходного GUID;
- очистка DNS-кэша без изменения постоянных сетевых параметров;
- профиль «Профиль низкой задержки» для безопасного набора настроек;
- выбор `FortniteClient-Win64-Shipping.exe` и точечная настройка fullscreen с возможностью отката;
- JSON-резервные копии в `%ProgramData%\\DXVPrivateTweek\\Backups` и журнал в `%ProgramData%\\DXVPrivateTweek\\Logs`;
- кнопки предварительного просмотра, применения, отката и сохранения отчёта.

Программа не отключает Defender, Firewall, Windows Update или системные службы, не меняет BCD/таймеры и не выполняет обход античита. Любое изменение выбирается вручную и отображается в журнале.

## Сборка `.exe`

В текущем Linux-окружении Windows SDK отсутствует, поэтому публикация выполняется на Windows или в Windows CI:

```powershell
dotnet publish .\\DXVPrivateTweek.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\\publish
```

Готовый файл будет `publish\\DXVPrivateTweek.exe`. Манифест приложения запрашивает права администратора. Перед применением изменений рекомендуется оставить включённой точку восстановления и проверить журнал.

## Как запускать

1. Скачайте ZIP релиза. Если релиза ещё нет, установите .NET 8 SDK на Windows, распакуйте исходники и запустите `.\build.ps1`.
2. Откройте `publish\\DXVPrivateTweek.exe` и подтвердите запрос UAC.
3. В первом окне оставьте включённым создание точки восстановления и нажмите «Продолжить».
4. Выберите нужные пункты, сначала нажмите «Показать изменения», затем «Применить выбранное».
   Для базового профиля нажмите «Профиль низкой задержки». Если хотите проверить fullscreen-настройку Fortnite, сначала нажмите «Выбрать Fortnite .exe» и укажите `FortniteClient-Win64-Shipping.exe`.
5. После проверки игры откатите настройки кнопкой «Откатить резервные копии». Журналы и копии находятся в `%ProgramData%\\DXVPrivateTweek\\Logs` и `%ProgramData%\\DXVPrivateTweek\\Backups`.

На ноутбуке включайте план высокой производительности только при подключённом питании. После применения перезапустите Fortnite и сравнивайте frametime/ощущения до и после каждого изменения.

Отрицательной задержки не бывает: программа может убрать лишние очереди и сделать задержку стабильнее, но не может сделать отклик раньше действия пользователя. Для Fortnite обычно помогают проводное подключение, ближайший регион, отсутствие фоновых загрузок и оверлеев, NVIDIA Reflex «On + Boost» при поддержке, отключённый V-Sync при допустимом tearing и стабильный лимит FPS чуть ниже частоты монитора при VRR. Проверяйте каждое изменение отдельно; не отключайте Defender, Firewall или обновления и не применяйте сомнительные MTU/BCD/timer/winsock-твики.
